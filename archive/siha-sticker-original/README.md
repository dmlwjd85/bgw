# 시하 스티커 원본 (보관용, 수정 금지)

삼봉님이 올린 스티커 PNG 원본입니다. **읽기만 하고 내용을 바꾸지 마세요.** 가공은 복사본(`siha-dress-book/public/sticker/`)에만 합니다.

이 폴더가 비어 있으면 앱은 이미 넣어 둔 가공본으로 동작합니다. 파이썬 재가공(`tools/build_sticker_assets.py`)을 돌리려면 아래 세 묶음을 채워 `STICKER_SRC` 가 이 폴더를 가리키게 하세요. 기본값이 바로 여기입니다.

## 묶음

| 묶음 | 폴더 | 내용 |
| --- | --- | --- |
| A | `4e40d8/` | 몸, 옷, 신발, 양말, 리본, 하늘 모눈종이 |
| B | `8d0099/` | 머리 장식, 소품, 연한 모눈종이 |
| C | `adb08a/` | 티아라, 리본, 보석 |

상대 경로는 부품 JSON 의 `from` 칸과 같습니다. 예: 묶음 A 의 노란 상의 → `4e40d8/yellow-crop-top/yellow-crop-top-2.png`

목록은 `manifest.json` 을 보세요.
