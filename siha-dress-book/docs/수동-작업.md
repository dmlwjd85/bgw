# 자동으로 부족한 그림 작업

원본은 만지지 않고, 복사본만 `tools/build_sticker_assets.py` 와 `tools/sticker_fit/finish_art.py` 로 가공합니다.

원본 묶음이 `archive/siha-sticker-original/` 에 있고 Real-ESRGAN 모델(`STICKER_ESR_MODEL`)이 있을 때만 **전체 재가공**(칼선 제거·4배 업스케일)이 됩니다. 이 저장소에는 이미 가공된 `public/sticker/` 복사본이 들어 있어 앱은 그대로 돌아갑니다.

## 스크립트가 하는 일

1. **흰 칼선 테두리 제거** (`tools/sticker_fit/rim.py`) — 바깥에서 이어진 흰 띠만 지우고, 가장자리는 부드럽게 두되 블러는 넣지 않습니다.
2. **4배 업스케일** (`tools/sticker_fit/esr.py`) — Real-ESRGAN anime 로 선을 선명하게 키웁니다.
3. **손 이음 조각** — 전신 시트에서 소매 밖 손을 떼어 `arms` 레이어 조각으로 만듭니다. (하늘 드레스, 곰 우주복)
4. **속바지 짧게** — 흰 반바지 밑단을 가장 짧은 치마보다 위로 다시 칠합니다. (`fixes.shorten_shorts`)
5. **배경 구멍 메우기** — 모눈종이 PNG 의 스티커 구멍을 같은 모눈으로 메웁니다. (`bgfill`) 검수 후 `finish_art.py` 가 격자를 깨끗하게 다시 그립니다.
6. **양말·신발 맞춤** — 다리 실루엣으로 양말을 다시 칠하고, 신발 밖으로 나온 맨발을 가립니다. 신발 안 양말 그림은 `front` 의 `onlyWith` 조각입니다.

### `finish_art.py` (가공된 복사본만, 원본 묶음 불필요)

- 몸을 **뒷머리 / 몸 / 얼굴 / 앞머리 / 흔드는 팔** 레이어로 나눕니다. (`characters/siha.json` 의 `pieces` + `face`·`bangs` 앵커)
- C자 머리 장식(밀짚모자, 헤드폰, 머리띠, 티아라, 뿔)을 **앞·뒤**로 잘라 머리가 사이에 끼게 합니다.
- 분홍 드레스·노란 상의에서 팔과 겹치는 부분을 **소매 이음**으로 뗍니다. 하늘 드레스·곰 우주복은 소매가 그림에 있으므로 흔드는 맨팔을 숨깁니다.
- 막대사탕 막대, 분홍 리본의 작은 구멍, 보석 리본 안쪽 틈을 복사본에서 메웁니다.
- 모눈 배경을 깨끗한 격자로 다시 그립니다.

트레이 썸네일은 자른 앞면 대신 원본 한 장을 쓰도록 부품 JSON 에 `"preview": true` 를 둡니다.

## 원본 묶음이 있어야만 하는 일

아래만 아직 **원본 A/B/C 시트**가 필요합니다. 가공된 한 장짜리 칼선 PNG 만으로는 더 나아지기 어렵습니다.

### 원본 보관

세 묶음 원본 PNG 는 이 저장소에 들어 있지 않습니다. `archive/siha-sticker-original/README.md` 의 목록대로 A/B/C 를 채워 주세요. 원본은 읽기만 하고 수정하지 않습니다.

### 입은 전신 시트에서 떼는 손·발 이음

하늘 드레스·곰 우주복의 손 조각은 원본 **전신 시트**(옷을 입은 그림)에서 뗐습니다. 분홍 드레스·노란 상의는 칼선 한 장뿐이라 소매 겹침만 복사본에서 잘랐고, 시트에 있는 것 같은 **손 자체**는 없습니다. 치마·원피스의 **뒷자락을 다리 사이로 감는 그림**도 전신 시트나 뒷면 원본이 있어야 자연스럽습니다.

### 업스케일 모델

Real-ESRGAN anime 6B ONNX 는 저장소에 넣지 않습니다. 재가공할 때만 `STICKER_ESR_MODEL` 로 경로를 넘깁니다.
