# 자동으로 부족한 그림 작업

원본은 만지지 않고, 복사본만 `tools/build_sticker_assets.py` 로 가공합니다. 아래는 스크립트가 하는 일과, **사람이 손으로 그려야 하는 일**입니다.

원본 묶음이 `archive/siha-sticker-original/` 에 있고 Real-ESRGAN 모델(`STICKER_ESR_MODEL`)이 있을 때만 전체 재가공이 됩니다. 이 저장소에는 이미 가공된 `public/sticker/` 복사본이 들어 있어 앱은 그대로 돌아갑니다.

## 스크립트가 하는 일

1. **흰 칼선 테두리 제거** (`tools/sticker_fit/rim.py`) — 바깥에서 이어진 흰 띠만 지우고, 가장자리는 부드럽게 두되 블러는 넣지 않습니다.
2. **4배 업스케일** (`tools/sticker_fit/esr.py`) — Real-ESRGAN anime 로 선을 선명하게 키웁니다.
3. **손 이음 조각** — 전신 시트에서 소매 밖 손을 떼어 `arms` 레이어 조각으로 만듭니다. (하늘 드레스, 곰 우주복)
4. **속바지 짧게** — 흰 반바지 밑단을 가장 짧은 치마보다 위로 다시 칠합니다. (`fixes.shorten_shorts`)
5. **배경 구멍 메우기** — 모눈종이 PNG 의 스티커 구멍을 같은 모눈으로 메웁니다. (`bgfill`)
6. **양말·신발 맞춤** — 다리 실루엣으로 양말을 다시 칠하고, 신발 밖으로 나온 맨발을 가립니다.

## 사람이 해야 하는 일

### 원본 보관

세 묶음 원본 PNG 는 이 저장소에 들어 있지 않습니다. `archive/siha-sticker-original/README.md` 의 목록대로 A/B/C 를 채워 주세요. 원본은 읽기만 하고 수정하지 않습니다.

### 옷 앞·뒤 분리, 손·발·양말 이음

원본이 이미 **잘린 스티커 한 장**인 옷(노란 상의, 치마, 분홍 드레스 등)에는 뒷장·소매 이음이 없습니다. 몸 뒤로 돌아가는 옷자락, 팔 구멍을 감싸는 소매, 양말·발 이음은 **손으로 투명 PNG 를 나누어** `front` / `back` / `connectors` 에 넣어야 합니다.

지금 자동으로 손 조각이 있는 것은 `dress_blue`, `onesie_bear` 뿐입니다.

### 뒷머리 · 얼굴 · 앞머리 레이어

시하 몸은 전신 한 장입니다. 13겹 표에는 `back_hair`, `face`, `front_hair` 가 있지만 그림이 분리되어 있지 않아 몸 레이어에 같이 있습니다. 머리 장식 아래/위로 머리카락이 자연스럽게 끼게 하려면 이 세 겹을 따로 그려 `characters/siha.json` 의 `pieces` 에 추가해야 합니다.

### 속바지·배경 검수

속바지 밑단과 모눈 구멍 메움은 자동이나, 색이 어색하거나 구멍이 남으면 복사본 PNG 를 고칩니다. 원본은 그대로 둡니다.

### 그림 자체에 뚫린 구멍

레이어 문제가 아니라 원본 그림에 투명 구멍이 있는 장식이 있습니다. (보석 리본 고리, 분홍 리본 꼬리, 막대사탕 막대 근처) 메우려면 복사본을 다시 칠해야 합니다.

### 업스케일 모델

Real-ESRGAN anime 6B ONNX 는 저장소에 넣지 않습니다. 재가공할 때만 `STICKER_ESR_MODEL` 로 경로를 넘깁니다.
